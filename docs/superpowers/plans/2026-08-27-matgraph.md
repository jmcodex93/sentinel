### Task 1: Pure engine `matgraph.py`

**Files:**
- Create: `plugin/sentinel/matgraph.py`
- Test: `tests/test_matgraph.py`

**Interfaces:**
- Consumes: `sentinel.matwire._match_channel(stem) -> channel|None` (verify exact name/signature by reading `plugin/sentinel/matwire.py:58-105` first — adapt the call, not the table), `sentinel.matwire.channel_colorspace(channel) -> "RS_INPUT_COLORSPACE_SRGB"|"RS_INPUT_COLORSPACE_RAW"`.
- Produces (exact names Tasks 2-4 import):
  - `CS_SRGB = "RS_INPUT_COLORSPACE_SRGB"`, `CS_RAW = "RS_INPUT_COLORSPACE_RAW"`
  - `PORT_TO_CHANNEL: dict[str, str]` — BRDF/utility DESTINATION port id → canonical matwire channel. Keys are full port ids for BOTH BRDFs (standardmaterial + openpbrmaterial) plus `displacement.texmap` and `bumpmap.input`; values are canonical channels (`basecolor`, `roughness`, `metalness`, `normal`, `height`, `emission`, `opacity`, `ao`, `specular`, `glossiness`).
  - `PASS_THROUGH_ASSETS: tuple[str, ...]` — asset-id substrings a destination trace may walk THROUGH: `rscolorcorrection`, `rsramp`, `rsmathinv`, `rscolorlayer`, `bumpmap` (the matwire-interposed utilities). Unknown node → trace stops, no port signal.
  - `infer_channel(filename, dest_port) -> (channel|None, source)` where source ∈ `"name" | "port" | "both" | "conflict" | None`.
  - `audit_colorspaces(entries) -> list[verdict]`; entry = `{"material", "file", "assigned", "dest_port"}`; verdict adds `{"channel", "source", "expected", "verdict"}` with verdict ∈ `ok | mismatch | conflict | auto_unverified | unknown | foreign_cs`.
  - `find_dead_nodes(node_ids, edges, root_ids, sink_ids) -> set[str]` — edges are `(from_id, to_id)` in data-flow direction; alive = everything that reaches roots ∪ sinks (ancestors, including the roots/sinks themselves); O(n+e) single BFS on the reversed adjacency.

**Verdict semantics to implement exactly (spec + spike):**
- `assigned is None` → `auto_unverified` (Info; never mismatch — spike: resolution unreadable).
- `assigned` not in `{CS_SRGB, CS_RAW}` and not None → `foreign_cs` (Info).
- channel inferable by exactly one signal → use it; by both and equal → `source="both"`; by both and different → `conflict` (Info, no channel-based judgment).
- no signal → `unknown` (silent).
- channel known and `assigned` in vocabulary: `ok` if `assigned == channel_colorspace(channel)` else `mismatch` (the only fixable verdict; carries `expected`).

### Task 2: Adapter `matgraph_c4d.py`

**Files:**
- Create: `plugin/sentinel/matgraph_c4d.py`
- Test: `tests/test_matgraph_c4d.py`

**Interfaces:**
- Consumes: Task 1 (`PASS_THROUGH_ASSETS`, `find_dead_nodes`, `CS_SRGB`/`CS_RAW`); maxon idioms from the spike (Global Constraints); `matwire_c4d` naming conventions (`_RS_CORE`, `_RS_OUTPUT`, `_ASSETID_ATTR` — mirror the constants, or import them if importing `matwire_c4d` is clean under the harness).
- Produces:
  - `collect(doc) -> list[per_material]`; per_material = `{"material": BaseMaterial, "name": str, "node_ids": [str], "nodes_by_id": {id: GraphNode}, "edges": [(from_id, to_id)], "samplers": [{"node_id", "path", "assigned", "dest_port"}], "root_id": str|None, "sink_ids": [str], "error": str|None}`. One walk per RS node material; non-RS/non-node materials skipped silently; any exception during a material's walk → that material returned with `error` set and empty lists (never raises out).
  - `write_colorspaces(doc, fixes) -> {"written": n, "materials": m}`; fixes = `[{"material": BaseMaterial, "node_id", "expected"}]`. **Whitelist guard**: any `expected` not in `{CS_SRGB, CS_RAW}` is skipped and counted, NEVER written (crash lesson). Per material: `AddUndo(UNDOTYPE_CHANGE, mat)` + one transaction. NO StartUndo bracket here (the caller owns it — fixes.py contract).
  - `clean_dead_nodes_core(doc) -> {"ok": True, "materials": n, "removed": k, "skipped": s}` — full batch in ONE `StartUndo`/`EndUndo`; per material anchor + transaction; a material with `error` or an unrecognized potential sink is skipped and counted (`skipped`), never touched; `{"ok": False, "error": "no_document"}` when doc is None. Dialog-free.
- Node id: use `str(node.GetPath())` as the stable per-walk id (unique within a graph read; NEVER persisted).
- Dest-port trace: from each sampler's `outcolor`, follow `GetConnections` downstream; while the target node's assetid matches `PASS_THROUGH_ASSETS`, continue from that node's outputs (first output port with connections); stop at the first non-pass-through target and report its full port id string; branch fan-out >1 at the sampler → report the first non-pass-through hit (document the choice in the docstring); trace depth cap 8.
- Roots: ALL connected input ports of the node whose assetid contains `node.output` → the nodes feeding them (plus the output node itself is never dead). Sinks: nodes whose assetid contains `storecolortoaov` / `storescalartoaov` / `storeintegertoaov` (case-insensitive substring).

## Self-review notes

- The spike collapsed decision 3's "auto resolves wrong → mismatch" branch to unreachable; the plan implements the surviving semantics (auto → Info always). If a future RS exposes resolution, that's a new feature.
- `GetConnections` returns the WIRE's target port; the adapter derives both the edge (node level) and the sampler's dest port from the same read — one walk, two consumers, per the spec.
- Info-row transport (metadata vs violations) intentionally mirrors an existing check rather than inventing a new channel — the implementer reads the model first (Task 3 Step 1).
