## Global Constraints

- **La cámara master NUNCA se muta** — crop/nudge viven como overrides en los Takes (invariante v1.8.0; por eso no hay "Restore Camera").
- **Draw es read-only estricto** (documento CLONADO; estado desde BaseContainer, jamás setattr — lección v1.8.0). El sync jamás corre desde Draw/Execute ni dentro de POSTSETPARAMETER (debounce deferred).
- **Cero MessageDialog en rutas de sync/ops** (un diálogo en un MessageData/drain congela C4D — patrón `_forbid_dialog`).
- Los IDs de parámetros existentes del tag NO cambian (escenas v1.8.0 cargan sin pérdida); los IDs de los botones retirados no se reutilizan.
- Formatos MÁS ANCHOS o iguales que master: resolución-sola (sin override de cámara), como hoy.
- Composition None: sin escritura de cámara + aviso honesto en HUD.
- QC #12 no cambia de semántica (mismo storage de nudge/insets).
- Registro de plugins nuevos → **reinicio completo de C4D** para verificar (no Reload Python Plugins).
- Versión objetivo: **v1.28.0**. Baselines: pytest 848, vitest 134.
- Plugin IDs: el MessageData nuevo usa **2099077** (siguiente libre tras SentinelPanelSPA 2099076).

```python
# --- Camera-type-aware crop writes (Frame v2) -------------------------------
# ORSCAMERA (native RS camera, C4D 2023.1+) has its OWN parameter namespace —
# Ocamera ids (APERTURE=1006, FILM_OFFSET) are inert on it. The v1.8.0 "RS
# ignores aperture" finding was an Ocamera-id-on-ORSCAMERA no-op, not an RS
# limitation. See docs/solutions/workflow-issues/2026-07-28-rs-camera-take-overrides.md
ORSCAMERA_TYPE = 1057516          # ajustar al valor confirmado en el spike
RS_SENSOR_SIZE = <id del spike>   # RSCAMERAOBJECT_SENSOR_SIZE (Vector)
RS_SENSOR_SHIFT_X = <id del spike>
RS_SENSOR_SHIFT_Y = <id del spike>

def detect_camera_kind(type_int):
    return "orscamera" if int(type_int) == ORSCAMERA_TYPE else "ocamera"

def crop_writes(kind, aperture, sensor, factor, nudge_film, src_film):
    """Pure table of (param_id, value) camera-override writes for a TRUE
    inscribed crop of `factor` (<1 narrower target; ==1 → no writes).
    Same optics both kinds: sensor crop keeps focal/DOF/zoom-keys intact."""
    if factor >= 1.0 - 1e-9:
        return []
    writes = []
    nx, ny = float(nudge_film[0]), float(nudge_film[1])
    sx, sy = float(src_film[0]), float(src_film[1])
    if kind == "orscamera":
        w, h = float(sensor[0]) * factor, float(sensor[1]) * factor
        writes.append((RS_SENSOR_SIZE, (w, h)))
        if abs(nx - sx) > 1e-9 or abs(ny - sy) > 1e-9:
            writes.append((RS_SENSOR_SHIFT_X, nx))
            writes.append((RS_SENSOR_SHIFT_Y, ny))
        return writes
    writes.append((CAMERAOBJECT_APERTURE, float(aperture) * factor))
    if abs(nx - sx) > 1e-9 or abs(ny - sy) > 1e-9:
        writes.append((CAMERAOBJECT_FILM_OFFSET_X, nx))
        writes.append((CAMERAOBJECT_FILM_OFFSET_Y, ny))
    return writes
```

- [ ] **Step 2: Implementar `frame_sync.py`**:
```python
"""Frame v2 auto-sync: the tag is the source of truth; Takes always mirror it.

SyncScheduler is PURE (injectable clock — no Date/time calls inside; the
caller passes `now`). FrameSyncMessageData is the c4d host: it receives the
SpecialEventAdd ping, polls the scheduler on CoreMessage + a coarse timer
tick, and runs the take regeneration ON MAIN THREAD outside any parameter
message. NEVER a MessageDialog here (freeze)."""
PLUGIN_ID = 2099077
EVENT_ID = 2099077
DEBOUNCE_SECONDS = 0.5

class SyncScheduler:
    def __init__(self, debounce=DEBOUNCE_SECONDS):
        self._debounce = float(debounce)
        self._pending = {}          # key (tag id) -> (sig, deadline)
        self._in_sync = False
    def mark_dirty(self, key, sig, now):
        if self._in_sync:
            return
        self._pending[key] = (sig, float(now) + self._debounce)
    def begin_sync(self): self._in_sync = True
    def end_sync(self): self._in_sync = False
    def due(self, now):
        out = []
        for key, (sig, deadline) in list(self._pending.items()):
            if float(now) >= deadline:
                out.append((key, sig))
                del self._pending[key]
        return out
```
